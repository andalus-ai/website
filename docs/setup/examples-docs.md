# Examples Docs

This page is the best entrypoint for Gollek’s examples surface.

Use it when you are trying to answer one of these questions:

- do I want plain code examples, JBang examples, or trainer JBang workflows
- where should I start if I want runnable examples instead of framework prose
- which examples page matches normal SDK usage versus specialized trainer flows

See also:

- [Examples](/docs/setup/examples)
- [JBang Examples Catalog](/docs/setup/jbang-examples)
- [Trainer JBang Docs](/docs/setup/trainer-jbang-docs)
- [Tutorials](/docs/tutorials/)

## Which Page Should I Read?

If you want plain SDK usage snippets and code patterns, start with:

- [Examples](/docs/setup/examples)

If you want runnable JBang scripts across many categories, start with:

- [JBang Examples Catalog](/docs/setup/jbang-examples)

If you want terminal-first training workflows, start with:

- [Trainer JBang Docs](/docs/setup/trainer-jbang-docs)
- [Trainer JBang Workflow](/docs/tutorials/advanced/trainer-jbang-workflow)

If you want guided learning paths rather than reference/example catalogs, start
with:

- [Tutorials](/docs/tutorials/)

## Do You Want Code Examples, JBang Examples, Or Trainer JBang Workflows?

If you want code examples embedded in docs pages, start with:

- [Examples](/docs/setup/examples)

If you want runnable JBang scripts for SDK, ML, multimodal, and trainer work,
start with:

- [JBang Examples Catalog](/docs/setup/jbang-examples)

If you want the trainer-specific terminal lane, start with:

- [Trainer JBang Docs](/docs/setup/trainer-jbang-docs)

Rule of thumb:

- `examples.md` means code patterns and copy-paste snippets
- `jbang-examples.md` means broad runnable scripts
- `trainer-jbang-docs.md` means terminal-first training families and workflow wrappers

## Main Surfaces

- [Examples](/docs/setup/examples)
  is the broad code-example page for common SDK and runtime usage patterns.
- [JBang Examples Catalog](/docs/setup/jbang-examples)
  is the broad runnable script catalog across beginner, neural-network, NLP,
  ML-integration, and multimodal examples.
- [Trainer JBang Docs](/docs/setup/trainer-jbang-docs)
  is the setup-side landing page for the trainer-specific JBang lane.
- [Tutorials](/docs/tutorials/)
  are the guided workflows when you want a narrative path instead of a catalog.

## Starter Paths

If you want the shortest SDK code-example path:

1. Open [Examples](/docs/setup/examples).
2. Start with the inference section that matches your use case.

If you want the shortest runnable-script path:

1. Open [JBang Examples Catalog](/docs/setup/jbang-examples).
2. Choose the category that matches your task.

If you want the shortest trainer path:

1. Open [Trainer JBang Docs](/docs/setup/trainer-jbang-docs).
2. Follow [Trainer JBang Workflow](/docs/tutorials/advanced/trainer-jbang-workflow).

## What’s Stable Vs Evolving?

The current stable-enough surfaces are:

- the docs code examples in `examples.md`
- the JBang examples catalog
- the trainer-JBang docs hub and workflow tutorial

The more likely-to-evolve areas are:

- exact example counts and category mixes in the JBang catalog
- newer trainer-family workflow wrappers
- some older setup/example prose that predates the newer hubs

Rule of thumb:
use this page to choose the examples lane first, then move into the matching
catalog or tutorial.
