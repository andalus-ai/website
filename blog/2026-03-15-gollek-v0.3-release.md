# 🚀 Gollek v0.3: Production-Ready AI Inference Platform

**March 2026**

We're excited to announce Gollek v0.3 - a major release that transforms Gollek from an ML framework into a **complete production-ready AI inference platform** rivaling Python-based solutions like vLLM and TGI, built entirely on the JVM.

---

## 🎯 What's New

### 1. vLLM-Equivalent Inference Serving

**Continuous Batching + PagedAttention** delivers 10-24x throughput improvement over traditional batching:

```
Traditional: Batch 1: [Req1, Req2, Req3] → Wait for all → Batch 2
Continuous:  [Req1✓, Req2, Req3, Req4] ← New requests added immediately
```

**Key Features:**
- ✅ Dynamic batch sizing based on KV cache availability
- ✅ Zero fragmentation paged KV cache (95%+ memory efficiency)
- ✅ Multi-turn conversation support
- ✅ Comprehensive metrics and monitoring

[📖 Learn More →](/docs/runtime/inference-serving)

### 2. Unified GPU Kernel SPI

Write once, run on any GPU. The new `ComputeKernel` SPI normalizes CUDA, Metal, and ROCm into a single interface:

```java
ComputeKernel kernel = ComputeKernelRegistry.get().getBestAvailable();
kernel.matmul(C, A, B, M, K, N);  // Works on any GPU
```

**Supported Backends:**
- **CUDA** - NVIDIA GPUs with cuBLAS, FA2/FA3
- **Metal** - Apple Silicon with MPS, FA4-equivalent
- **ROCm** - AMD GPUs with rocBLAS
- **CPU** - Pure Java fallback

[📖 Learn More →](/docs/runtime/gpu-kernel-spi)

### 3. Provider Fallback Router

Never lose an inference request to provider failure. The router automatically fails over through a prioritized chain:

```
OpenAI (primary) → Anthropic (fallback) → Local GGUF (last resort)
```

**Features:**
- ✅ Cost-aware routing (respects budget limits)
- ✅ Circuit breaker pattern (auto-recovery)
- ✅ Per-provider metrics and monitoring
- ✅ Quota management

[📖 Learn More →](/docs/runtime/provider-fallback-router)

### 4. 15 Configurable Optimization Plugins

All optimizations are **enabled by default** for maximum performance, but individually configurable:

| Plugin | Default | Impact |
|--------|---------|--------|
| PagedAttention | ✅ | +10-24x throughput |
| FlashAttention | ✅ | +2-3x attention speed |
| Continuous Batching | ✅ | +5-10x throughput |
| Prompt Cache | ✅ | 5-10x system prompt speedup |
| QLoRA | ❌ | Fine-tuning support |

```properties
# Disable specific optimization
gollek.optimizations.flash-attention.enabled=false

# Change block size
gollek.optimizations.paged-attention.blockSize=32
```

[📖 Learn More →](/docs/optimization-config)

## 🚀 Getting Started

### Installation

```bash
# Install via SDKMAN (recommended)
sdk install gollek

# Or use JBang for quick start
jbang --deps tech.kayys.gollek:gollek-engine:0.3.0 inference.java
```

### Quick Start

```java
// Get best available GPU kernel
ComputeKernel kernel = ComputeKernelRegistry.get().getBestAvailable();

// Create scheduler with continuous batching
ContinuousBatchingScheduler scheduler = ContinuousBatchingScheduler.builder()
    .maxBatchSize(256)
    .kvCacheManager(kvCacheManager)
    .build();

// Submit requests
scheduler.submit(new ScheduledRequest("req-1", "Hello!", 100));
```

### Configuration

All optimizations are enabled by default. Customize in `application.properties`:

```properties
gollek.optimizations.paged-attention.blockSize=16
gollek.optimizations.continuous-batching.maxBatchSize=256
gollek.optimizations.flash-attention.enabled=true
```
